# Anish Structural Portfolio

## Run locally
1. Install Node.js (18+ recommended).
2. Open a terminal in this folder.
3. Run:
   npm install
   npm run dev
4. Open the local URL Vite prints.

## Build
npm run build

The portfolio uses only information supplied in Anish's resume. The G+27 visualization is an intentionally schematic, non-engineering drawing and is labeled not to scale.
